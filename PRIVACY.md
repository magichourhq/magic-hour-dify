# Privacy policy

Last updated: September 22, 2026

This plugin sends the configured Magic Hour API key, generation parameters, prompts, and uploaded input images to Magic Hour to perform the requested operation. Input images are uploaded through a time-limited Magic Hour upload URL. Project status and time-limited output download URLs are returned to Dify.

The plugin's outbound requests go only to Magic Hour. It does not include analytics or persist user data itself. Dify and Magic Hour may retain data according to their respective settings and policies. Review the [Magic Hour privacy policy](https://magichour.ai/privacy) before using the plugin with personal or confidential content.

Delete projects or API keys through Magic Hour. Remove the plugin credential in Dify to stop future authenticated requests.
